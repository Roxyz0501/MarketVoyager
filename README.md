# Market Voyager

Roxyz0501による新規独立Dalamudプラグイン。購入リストに沿ってリムサを拠点にワールドを巡回し、通常のマーケットUIから購入します。Market Sweepとは別のプラグインです。

**1.0.1.4は公開プレビューです。** ビルド・購入条件・所持数照合・バックグラウンドUI描画を検証済みですが、ゲーム内での実際の移動、検索、購入、NPC売却・復帰、警告確認、DC切替は未検証です。通常UIの構造や連携プラグインの対応状況により停止する場合があります。

1.0.1.4では、検索欄を通常のフォーカス処理で有効にしてから入力します。対象アイテムの出品一覧が既に開いている場合も購入判定へ進み、クリック前に処理が中断された出品を候補から除外しません。上部に直近の出品数・購入候補数を表示します。停止後は未確認取引があっても行を削除でき、照合に必要な記録のみ別に保持します。リスト設定の位置を固定し、次のワールドへ移る前はメインエーテライトへ徒歩で戻ります。

前の版で未確認購入が残っている場合は、ゲームの購入確認画面を閉じ、所持品を確認して「購入していないことを確認して解除」を選べます。未購入なら購入済み数は増えません。所持数が予定分増えている場合は、停止後も購入済み数と自動売却対象へ計上します。新しい版で送信前の確認をキャンセルできた分は、自動照合後に解除します。

## 必須プラグイン

| プラグイン | 用途 |
|---|---|
| [Lifestream](https://github.com/NightmareXIV/Lifestream) | リムサを指定したワールド移動。別論理DCを含むエーテライト経路への対応版が必要 |
| [vnavmesh](https://github.com/awgil/ffxiv_navmesh) | 経路探索とマーケットボードまでの徒歩移動 |

設定タブに導入・読み込み状態を表示します。導入済みでもIPCの互換性、ナビメッシュの準備、ゲーム内の移動可否は別途必要です。非対応の連携口やタイムアウトでは停止します。プラグインを自動でインストールしたり、依存側の設定を書き換えたりしません。

巡回は同じ物理リージョン内の公開ワールドのうち、Lifestreamが訪問候補として返すものを対象にします。別論理DCも対象です。タイトル画面を経由する旧DC移動や別物理リージョンへの移動は依頼しません。混雑等による移動制限を回避しません。旧Lifestreamの公開ソースと導入ファイルには旧DC移動経路が残っているため、**別論理DCへの実動作は特に未確認**です。

## 使い方

1. Lifestreamとvnavmeshを有効にします。
2. `/marketvoyager` を開き、購入リストを作成します。最大50リスト、各1,000行。「アイテム追加」タブで名前（1文字から）・ID・マーケットのジャンル・NPC売却価格の下限を組み合わせ、価格・名前・ジャンル・アイテムレベル・IDで並べ替えられます。表示は30行ごとのページです。
3. 追加用の単価・購入上限数・品質を指定し、選択品を追加します。検索結果全体なら「検索結果を全選択」→「選択した品を一括追加」を使います。登録後も選択行・全行に価格／上限数／品質を個別に選んで一括適用できます。重複品質や1,000行超の操作はまとめて拒否します。
4. リムサ・ロミンサ下甲板層のメインエーテライト付近（25m以内）で、既存のマーケット・確認画面を閉じて開始します。
5. 選択したリストを巡回購入します。停止ボタンまたは `/marketvoyager stop` で止められます。

単価上限は**以下**です。5,000なら単価5,000を含めます。初期値は税別で、「手数料・税込みで判定」をオンにすると総額÷数量が5,000以下の出品が対象です。これは総支出上限ではありません。単価5,000、数量3なら15,000ギル＋税になります。所持金は税込総額に対して確認します。

品質はNQのみ、HQのみ、無視（どちらでも）の3択です。「無視」はHQとNQを合算して数量上限を守ります。HQのないアイテムはNQに正規化します。同じアイテムの重複条件・「無視」とHQ/NQの重複は開始時に拒否します。

購入数は出品件数ではなくアイテム個数です。残数を超えるスタックは買いません。数量は全ワールド横断で保存され、停止や再起動で自動リセットしません。選択行だけ、またはリスト全行の購入済み数をリセットできます。リセットと価格・上限変更は自動売却用の未売却数を変更しません。複数リストの同時実行は行いません。

## 整理した画面と操作

- 上部に「開始」「一時停止／再開」「停止」を常設。どのタブでも操作できます。一時停止は進行中の購入・売却・移動の確認を終えた安全な区切りで入り、再開時に同じワールド・リストの続きを進めます。停止は巡回を終了します。
- 「登録済みアイテム」は1アイテム1行。名前・品質・単価上限・税込・購入上限・購入済み・NPC価格を横並びに表示し、その場で編集できます。ヘッダーと名前列を固定し、表の中だけをスクロールします。名前検索、30行ごとのページ、列幅調整に対応します。
- 「アイテム追加」は検索して選択→単価・数量・品質を指定→追加の流れ。ジャンル・NPC価格下限・並び順を上部にまとめ、NPC価格からの自動設定は必要なときだけ展開します。
- 登録済みの一括変更は一覧上部の「まとめて変更」ボタンから開きます。「選択した行」または「登録済みの全行（検索外を含む）」を選び、変更する項目にチェックして適用します。行を選ばなくても全登録行へ一括適用できます。価格・数量・品質の一括編集、NPC価格−差額の一括設定、購入済み数リセット、削除に対応します。
- 各行の「…」にはNPC価格−差額の設定、購入済み数リセット、削除があります。リスト名や自動売却条件は「リスト設定」にまとめています。

NPC価格−差額の専用一括操作は価格と税込設定だけを更新し、品質・購入上限数・購入済み数・未売却数を保持します。

## NPC価格からの上限設定

「NPC売却価格」はNPCに売ったときの受取額です。NPCから購入するときの価格ではありません。NQの基準額を使用し、HQも保守的に同じ基準額を使います。

「NPC売却価格から差額を引いて税込上限を設定」をオンにすると、追加・一括変更時に `NPC売却価格 − 指定差額` を税込単価上限として設定します。登録済みの各行の「…」と「選択項目の操作」から単体・一括で設定できます。例えばNPC売却価格100、差額5なら、実際のマーケット税を含む総額が `95 × 個数` 以下の出品だけを購入します。差額は最低1ギルで、価格が差額以下の品はこのモードでは追加されません。装着マテリア等の加算は計算に含めません。

## 自動売却と購入再開

購入リストごとの「購入品をNPCへ自動売却」は初期オフです。オンにすると通常所持品4ページ（140枠）の空き枠が設定値以下になった時点で購入を中断し、近くの通常ギルショップNPCへ移動します。0なら満杯時、5なら残り5枠以下で売却を開始します。売却後は同じワールドの最寄りマーケットへ戻り、中断したアイテムから再開します。巡回途中で満杯になった場合もこの経路を使います。売却できず空き枠が0のままなら停止します。

**売却は購入済み数を減らしません。** 上限100個を購入して売却しても購入済みは100のままです。売却対象は選択リストのうち、このプラグインが購入確認した未売却分で、キャラクター・HQ/NQ別に保存します。元から持っていた数量を余分に売らないよう、未売却分で全数量をまかなえるスタックだけを売ります。元の所持品と混ざってその範囲を超えたスタック、マテリア付き・ミラプリ済み・錬精進行品・収集品・売却不可品は除外します。クリスタル専用枠・アーマリーチェスト・リテイナーは対象外です。

ショップを直接開ける通常ギルNPCを現在地から150m以内で選びます。クエスト・交換・複数メニューのNPCは使いません。通常の所持品コンテキストメニュー「売却」、数量入力、関連した確認ボタンを使います。売却結果は所持数の減少とギル増加で照合し、結果不明時に売却を繰り返しません。購入結果の照合と売却を同時に進めないため、売った分を購入失敗として再購入することはありません。

未確認売却が残った場合は所持品とギルを確認してください。「未確認分を自動売却対象から除外して解除」は、その数量を今後の自動売却から除外します。購入済み数には影響しません。手動で購入済み扱いにした未確認購入は、自動売却対象には加えません。

## 購入とリトライ

- ゲームの検索入力・検索ボタン・出品行・確認ボタンのUIイベントを使います。購入パケットの構築・直送、購入要求関数の直接呼び出しはありません。
- 出品ID、アイテム、品質、単価、数量、税、所持金、残数を確認します。自分の出品、マネキン、セット販売を除外します。
- 購入警告は選択中の出品と関連付けできた購入確認・装備不可確認のみ処理します。無関係な確認を一括承認しません。
- 出品取得のタイムアウトでは出品一覧を閉じて検索から最大3回開き直します。マーケット自体が閉じていればボードへ戻って開き直します。
- 購入直前のHQ/NQ別所持数と購入予定を保存します。購入通知が欠落した場合、所持数が購入数分増えていれば完了として計上します。
- 結果が20秒届かず所持数も増えていない場合、画面を開き直して**同じ出品ID・同じ条件**だけを最大2回再試行します。結果未確認のまま別出品に乗り換えません。
- 所持数が予想外に変化した場合、元出品が見つからない場合、未知の警告や再試行上限では停止します。実行中は同じアイテムの手動移動・使用・売買を避けてください。
- 購入中のログアウトでは最大120秒再接続を待ちます。再接続操作自体は行いません。プラグイン再読み込み後も未確認の購入を保持し、自動再購入を止めます。必要なら所持品を確認して「未確認分を購入済みとして計上」を使用します。
- YesAlreadyがある場合、実行中・未確認購入／売却がある間のみ公式共有停止リストへ登録します。必須ではありません。

## 言語

日本語、English、Deutsch、Français、한국어、简体中文、繁體中文に対応します。初回だけゲーム言語→Dalamud UI言語→英語で決定し保存します。公開ランチャー言語APIは使用していません。保存済み選択はゲーム起動時に変更しません。「言語設定」タブから即時変更できます。Autoはありません。

アイテム名はゲームデータの言語を使います。UIを韓国語・中国語にしても、ゲームデータにない翻訳は作りません。Dalamud提供のNoto Sans CJKで字形を補います。共通タブは設定→言語設定→支援の順です。

```powershell
dotnet build MarketVoyager/MarketVoyager.csproj -c Release
dotnet run --project Tests/Tests.csproj -c Release
dotnet run --project Tests/Native/NativeTests.csproj -c Release
dotnet run --project Tests/UI/UiTests.csproj -c Release -- '<game-directory>' 'artifacts/ui'
```
